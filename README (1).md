# ElectroReck: Techspardha Event Page

Responsive event page for ElectroReck, the electrical club of NIT Kurukshetra.
Built with HTML, CSS (Flexbox + Grid) and vanilla JavaScript.

- Sticky nav, hero section, grid of 4 event cards (image, category badge, date/time, Register)
- Category filter (All / Technical / Creative / Academic)
- Registration modal with validation; registrations saved in localStorage
- Keep the `images` folder next to `index.html`

Open `index.html` to run. Deploy with GitHub Pages (Settings > Pages > main / root).
